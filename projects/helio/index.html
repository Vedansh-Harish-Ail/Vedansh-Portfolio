warning Cloud Storage Vulnerability

Standard cloud document stores hold server-side encryption keys, allowing insider indexing, data breaches, and unauthorized access to passports, medical files, and financial records.

Architecture Overview

Consumer cloud storage platforms often retain server-side keys to index and scan user documents. Helio introduces a zero-knowledge architecture where document payloads are encrypted on the client or during authenticated ingestion using keys derived directly from user passphrases via PBKDF2-HMAC-SHA512.

The backend database stores only metadata, access permissions, and encrypted ciphertext payloads with authentication tags, ensuring that even in the event of an infrastructure breach, raw documents remain mathematically indecipherable.

— ENGINEERING CHALLENGES & RESOLUTIONS

memory Challenge: Memory Spikes During Multi-GB File Ingestion

Encrypting monolithic multi-gigabyte files caused server out-of-memory crashes on memory-constrained containers.

Resolution: Architected an asynchronous streaming generator pipeline that encrypts fixed 64KB blocks sequentially with rolling GCM authentication tags.

key Challenge: Key Recovery Without Central Custody

Zero-knowledge architectures result in permanent data loss if users forget their master passphrase.

Resolution: Implemented a Shamir-inspired offline multi-fragment recovery sheet that splits the encrypted recovery key into printable paper shards.
