Helio: Encrypted Personal Document Vault

An authenticated, zero-knowledge digital document repository designed to protect sensitive personal records with AES-256-GCM encryption, tamper-proof SHA-256 integrity verification, and granular role-based permissions.

View on GitHub code Explore Architecture account_tree
Security Model AES-256-GCM / PBKDF2
Backend Python / FastAPI
Data Store PostgreSQL / SQLite
Status Active Development

Architecture Overview

Consumer cloud storage platforms often retain server-side keys to index and scan user documents. Helio introduces a zero-knowledge architecture where document payloads are encrypted on the client or during authenticated ingestion using keys derived directly from user passphrases via PBKDF2-HMAC-SHA512.

The backend database stores only metadata, access permissions, and encrypted ciphertext payloads with authentication tags, ensuring that even in the event of an infrastructure breach, raw documents remain mathematically indecipherable.

Key Security Pillars

lock

Authenticated Encryption

AES-256-GCM ensures both strict confidentiality and ciphertext integrity detection, alerting against unauthorized file tampering.

history

Immutable Audit Logging

Every file decryption, download, or sharing access event is logged with cryptographic hashes and timestamps.

badge

Scoped RBAC

Time-bound temporary sharing links with optional password challenge and single-view self-destruct capabilities.
