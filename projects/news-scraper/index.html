— ENGINEERING CHALLENGES & RESOLUTIONS

warning Challenge: Fragile Remote DOM Structure Changes

Publication redesigns frequently break rigid CSS path selectors, resulting in silent scraping failures.

Resolution: Engineered heuristic fallback extractors combining meta-tag parsing (`og:title`, `twitter:description`) with regex keyword matching when structural selectors fail.

speed Challenge: Upstream Latency & Rate Limiting

Slow external news servers caused client request timeouts when loading the dashboard synchronously.

Resolution: Implemented time-to-live (TTL) memory caching with background refresh workers so users always receive instant responses from cache.
