ResumeCraft: Privacy-First ATS Resume Builder

A browser-native resume builder delivering real-time split-pane live preview, standard Harvard ATS formatting, and 100% client-side data privacy where user credentials never touch an external database.

Open Live Builder north_east GitHub Repository code
Privacy Model 100% Client-Side Only
Compliance Harvard ATS Standard
Rendering Engine Dynamic DOM & CSS Paged Media
Import Engine Mozilla PDF.js Parser

The Problem & Privacy Mandate

Most modern commercial resume builders enforce predatory subscription paywalls right at the download screen and harvest personal phone numbers, addresses, and employment records into marketing databases.

ResumeCraft was created as an open-access, zero-telemetry alternative. Every keystroke is updated in memory using reactive event listeners and saved exclusively to the user's browser `localStorage`. No data is transmitted across the wire.

Core Capabilities

Instant Dynamic Preview

Debounced inputs mirror live changes into an exact 8.5" x 11" printable sheet with zero layout jumping.

ATS Machine-Readability

Strict semantic hierarchy with standard headings ensuring 100% parse accuracy across Greenhouse, Lever, and Workday.

One-Click Vector PDF

Exports clean vector text rather than blurry canvas screenshots, ensuring selectable copy and small file footprint.
