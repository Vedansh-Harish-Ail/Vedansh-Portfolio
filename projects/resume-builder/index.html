— ENGINEERING CHALLENGES & RESOLUTIONS

print Challenge: Cross-Browser Print Consistency

Different browser rendering engines handle page margins, header headers, and pagination page-breaks inconsistently during PDF export.

Resolution: Calibrated `@page { size: letter; margin: 0.5in; }` rules and `break-inside: avoid` constraints across all section containers to guarantee identical layout on Chrome, Firefox, and Safari.

speed Challenge: Split-Pane DOM Reflow Throttling

Rapid continuous keystrokes in large work experience descriptions caused cumulative layout shifts and visible input stutter.

Resolution: Implemented requestAnimationFrame-throttled DOM reconciliation that updates only modified text nodes without triggering full document reflows.
