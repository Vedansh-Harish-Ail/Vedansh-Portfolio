An asynchronous Python service daemon built to automate enterprise document print pipelines. Handles automated preflight PDF inspection, color profile standardization, SLA-weighted queue scheduling, and fault-tolerant socket transmission over IPP and raw TCP printing protocols.

— ENGINEERING CHALLENGES & RESOLUTIONS

network_check Challenge: Silent Hardware Disconnections

Network printers frequently drop TCP sockets mid-transmission without sending TCP FIN/RST packets, leaving jobs hanging in limbo.

Resolution: Implemented dual-channel health checking combining TCP keep-alive probes with active SNMP MIB status queries, safely requeuing interrupted jobs without duplication.

sync Challenge: Head-of-Line Blocking Under Heavy Load

Massive 2,000-page batch reports locked primary print queues for hours, starving urgent single-page executive print requests.

Resolution: Architected a work-stealing multi-queue dispatcher with virtual lane segregation that dynamically partitions high-volume and low-latency workloads.
