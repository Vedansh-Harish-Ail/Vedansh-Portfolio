Meri Panchayat: Public Issue Reporting Portal

A localized civic grievance reporting portal engineered to bridge the divide between citizens and panchayat administrators, featuring passwordless Email OTP verification, granular role-based access control, and a custom Kannada translation engine.

Open Live Portal north_east GitHub Repository code
Architecture MVC via Python / Flask
Security Email OTP & Granular RBAC
Localization English & Kannada (i18n)
Data Layer SQLite / Relational Schema

The Challenge

In many regional communities, citizens encounter significant friction when reporting urgent municipal breakdowns—such as contaminated water lines, road hazards, or electricity failures. Complaints made in person are frequently lost in physical registers, lack accountability, and offer no tracking mechanism.

Furthermore, existing municipal software platforms often mandate complex password accounts and are published exclusively in English, isolating regional residents who speak Kannada.

Solution & Engineering Details

mark_email_read Passwordless OTP Authentication

Engineered a secure 6-digit Email OTP verification workflow with time-limited tokens and rate limiting. This eliminates password fatigue for rural users while ensuring verified citizen identities.

translate Custom i18n Localization Engine

Implemented a lightweight JSON-backed internationalization engine that enables instantaneous client and server language switching between English and Kannada without page reload lag.

Core Capabilities

track_changes

Complaint Lifecycle Tracking

Unique tracking IDs with real-time status transitions: Submitted → In Review → Work Dispatched → Resolved.

admin_panel_settings

Role-Based Access Control

Strict session isolation separating citizen grievance submission views from administrative triage and resolution dashboards.

query_stats

Administrative Analytics

Built-in aggregation metrics tracking resolution velocity, category-wise breakdown, and open municipal backlog.

Quality Engineering & Testing

To guarantee system resilience under concurrent usage, automated test scripts were written in Python to validate:

  • OTP Expiry & Replay Prevention: Rigorous boundary testing ensuring single-use token invalidation within 300 seconds.
  • SQL Query Sanitization: Parametric query validation preventing SQL injection attempts across complaint title and description fields.
  • Concurrent Load Verification: Simulated 100+ concurrent reporting sessions to confirm SQLite transaction locking stability and response latency under 120ms.
